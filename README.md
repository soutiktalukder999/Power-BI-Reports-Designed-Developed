# 🧮 HR DAX

## Attrition Rate

```DAX
Attrition Rate =
DIVIDE(
    CALCULATE(
        COUNTROWS(HR_Analytics),
        HR_Analytics[Attrition] = "Yes"
    ),
    COUNTROWS(HR_Analytics)
)
```

---

## Average Salary

```DAX
Average Salary =
AVERAGE(
    HR_Analytics[MonthlyIncome]
)
```

---

## Salary Slab

```DAX
Salary Slab =
SWITCH(
    TRUE(),
    HR_Analytics[MonthlyIncome] <= 5000, "Upto 5K",
    HR_Analytics[MonthlyIncome] <= 10000, "5K–10K",
    HR_Analytics[MonthlyIncome] <= 15000, "10K–15K",
    "15K+"
)
```

---

## Attrition by Role

```DAX
Attrition by Role =
CALCULATE(
    COUNT(HR_Analytics[EmployeeID]),
    HR_Analytics[Attrition] = "Yes"
)
```
